# Ko'chatxona 3D: Muzrabod greenhouse

Interactive 3D model of a seedling greenhouse complex built for **UZ GROW**, with a profit calculator next to it.

**Live:** https://3d-issiqxona-ten.vercel.app

- Full 3D greenhouse in React Three Fiber: frame, film, side curtains, irrigation, three 26×40 m buildings
- 7 crops (tomato, pepper, eggplant, cucumber, grafted watermelon, cabbage, strawberry), each with its own leaf model
- Two modes: selling seedlings or growing a harvest
- Economics calculator: cost, price, cycles per year and yearly profit; every number is editable
- Camera presets (overview, top, inside, rack, field), LOD and quality settings for weak devices

## Stack

React 19 · TypeScript · Vite · Three.js · React Three Fiber · drei · postprocessing

## Run

```bash
npm install
npm run dev
```
